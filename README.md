# RF crates

A Cargo workspace for four public RF engineering libraries:

- `rfconversions`: scalar RF conversions and numerical operations.
- `touchstone`: S-parameter file parsing and network analysis.
- `gainlineup`: ordered RF hardware cascade analysis.
- `linkbudget`: terrestrial and satellite link budgets.

The workspace is under construction. Original repository histories and licenses
are preserved during import. No private application source belongs here.
